# 🚀 全機能統合パック (All-in-One Full Pack)

すべてのカスタム機能（ビジュアルバータイマー、学習進捗予測、テーマ切替、単語クリップ、意味欄整形）が統合された完全版テンプレートです。

## 📁 構成ファイル
- `front.html`: 表面テンプレート
- `back.html`: 裏面テンプレート
- `style.css`: スタイルシート (CSS)

## 🛠 導入手順
1. Ankiデスクトップのメニューから **「ツール」→「ノートタイプを管理」** を開きます。
2. 使用しているノートタイプを選択し、**「カード」** をクリックします。
3. **「表面の書式」** に `front.html` の内容を貼り付けます。
4. **「裏面の書式」** に `back.html` の内容を貼り付けます。
5. **「書式（CSS）」** に `style.css` の内容を貼り付けます。
6. (学習予測機能を使用する場合) `modules/02-study-forecast/_deck_forecast.js.template` を自身のデッキ枚数に合わせて書き換え、Ankiの `collection.media` フォルダに `_deck_forecast.js` として保存します。
