# 🏁 Module 2: Study Forecast & Completion Predictor (学習完了予測 HUD)

現在の解答ペースと過去のミス率・再出題率を自動計測し、「本日の学習終了予定」や「全カード制覇までの所要時間」をリアルタイム予測するHUDです。

## ✨ 主な特徴
- **高度なペース計算**:
  - カードめくり速度（秒/問）をローカルにサンプリングして直近ペースを動的に反映。
  - ミス・再出題率（約46%）を加味した「実質解答予測回数」からリアルな完了時刻（例: `明日 17:01`）を算出。
- **デュアルモード切替**:
  - 📅 **本日の学習分**: 今日期日の復習・新規カードの消化予測。
  - 📚 **全カード完走**: 未学習を含むデッキ全カードの完走予測。
- **デュアルスコープ切替**:
  - 🌍 **全体**: 全Part合算
  - 📖 **このPartのみ**: 現在解いているデッキ単体

## 🛠 導入方法
1. `_deck_forecast.js.template` を基に自身のデッキ枚数を設定し、Ankiの `collection.media` フォルダに `_deck_forecast.js` として保存します。
2. テンプレートの最上部に `<script src="_deck_forecast.js"></script>` を追加します。
3. `template.html`, `style.css`, `script.js` をそれぞれのカード書式に追加します。
