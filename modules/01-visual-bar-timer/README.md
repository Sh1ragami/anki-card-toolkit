# 📊 Module 1: Visual Bar Timer (キングジム VBT20風 ビジュアルバータイマー)

キングジムの人気タイマー「ビジュアルバータイマープラス（VBT20）」を再現した、画面最下部常駐型のプログレスバータイマーです。

## ✨ 主な特徴
- **4色のカラーゾーン（20分割）**:
  - `75% 〜 100%`: 余裕のブルー（青 `#1173f0`）
  - `50% 〜 75%`: 順調なグリーン（深緑 `#08ac5d`）
  - `25% 〜 50%`: 折り返しのライム（黄緑 `#90d312`）
  - `0% 〜 25%`: 警戒のオレンジ（橙 `#e17911`）
- **ゼロ・ディレイ即時同期 (Anti-Flicker)**: 画面描画（Paint）前に現在値を瞬時に算出・適用するため、カードをめくった瞬間の跳ねやチラつきが一切ありません。
- **2つのモード切替**:
  - ⏳ **残り勉強時間 (全体)**: 15分/25分(ポモドーロ)/45分/60分の学習時間消化バー
  - ⚡ **1問の制限時間 (8秒)**: 1問ごとに8秒からゼロに向かって縮むタイムアタックバー
- **シンプルな太字数字**: 右下に邪魔にならないミニマルなデジタル表示。タップで時間変更メニューが開きます。

## 🛠 導入方法
1. `template.html` の内容を、表面・裏面テンプレートの最下部に貼り付けます。
2. `style.css` の内容を、Ankiの「書式（CSS）」に貼り付けます。
3. `script.js` の内容を、表面・裏面テンプレートの `<script>` 内に貼り付けます。
