# 📎 Module 4: Quick Clip / Pocket HUD (単語ストック機能)

学習の流れを止めることなく、「あとで修正したい単語」や「復習したい単語」を1タップでストック・一覧管理できるクリップ機能です。

## ✨ 主な特徴
- **1タップ保存**: ヘッダーの `📎` を押すだけで、単語番号と単語がローカルに保存され、一瞬 `✅` に変化します。
- **保存済みリスト展開**: もう一度 `📎` を押すと保存一覧パネルが展開します。
- **ワンクリック一括コピー (`📋 COPY`)**: クリップボードに改行区切りで即座にコピーし、NotionやChatGPT、メモ帳に貼り付けて一括見直しできます。
- **個別削除 (`×`) & 全消去 (`CLEAR`)**
