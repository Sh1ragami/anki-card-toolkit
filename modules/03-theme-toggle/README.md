# 🌙 Module 3: Instant Theme Toggle (ダーク ⇄ グリーン切替)

目に優しいソフトスプリンググリーン（`#B6BDA7`）と、真の漆黒OLEDトゥルーブラック（`#000000`）をワンタップで切り替える機能です。

## ✨ 主な特徴
- **カードをまたぐ状態保持**: `localStorage` を使用し、AnkiMobileやAnkiDroidでもテーマ設定が維持されます。
- **ゼロ・フリッカー先行適用**: カードテンプレートの最上行でスタイルを事前注入するため、カードをめくった際に画面が一瞬白く光るチラつき（白飛び）が起きません。
- **ミニマル絵文字ボタン**: ヘッダーの `🌙` / `☀️` ボタンだけでシームレスに切り替わります。

## 🛠 導入方法
1. `template.html` の先頭スクリプトをカードの1行目に、ボタン部分をヘッダーに配置します。
2. `script.js` をメイン `<script>` ブロックに配置します。
