# Meaning Formatter

辞書データ（CSV）の意味欄に含まれる各種記号を解析し、視認性の高いレイアウトへ自動整形します。

## 仕様
- **定義分離 (`＝`)**: 同義語や補足定義をメインの意味から分離し、フォントサイズと色を調整。
- **ブラケットタグ化**: `【品詞】`、`〔語源〕`、`《専門用語》`、`<英語解説>` などを個別の視覚タグに自動変換。
- **訳語ハイライト**: 例文の日本語訳の中から、対象の英単語に対応する語句を赤色で強調表示。

## ファイル
- `style.css`: 整形後タグ・ハイライト用スタイル
- `script.js`: DOMパーサーおよび正規表現置換ロジック

## 導入
1. `style.css` をスタイルシート（CSS）に追加。
2. `script.js` を裏面テンプレートの `<script>` に追加。

## TIPS: 手動ハイライト（Edge Case対応）
「例文の訳が第二語義を採用している」「意訳されすぎて自動マッチしない」等の理由でハイライトが機能しないカードに対しては、`Example_JA` フィールド内で手動でタグ付けを行うことができます。

**例:**
`図書館では静かに<span class="target-word-ja">してい</span>なくてはならない。`

自動処理スクリプトは、既に `<span class="target-word-ja">` が存在する場合は処理をスキップするため、手動指定が上書きされることはありません。
