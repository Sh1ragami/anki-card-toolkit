# ✨ Module 5: Meaning Formatter & Symbol Cleaner (意味欄整形・自動ハイライト)

アルク（ALC）「究極の英単語」や市販辞書CSVの意味欄に含まれる各種記号を解析し、美しいモダンタイポグラフィに自動整形するパーサーです。

## ✨ 主な機能
- **`＝` 同義語・定義の自動分離**: メインの意味と、`＝` 以降の補足解説を自動検出し、色とサイズを落ち着かせて分離表示。
- **ブラケット記号のカラーバッジ化**: `【品詞】`、`〔語源〕`、`《専門用語》`、`<英語解説>` などを個別のタグスタイルに自動変換。
- **例文日本語訳のターゲット語自動ハイライト**: 英文中のターゲット英単語に対応する日本語訳部分を検出し、赤色でハイライト表示。

## 🛠 導入方法
1. `style.css` をAnkiのスタイルシートに追加します。
2. `script.js` を裏面テンプレートの `<script>` に追加します。
